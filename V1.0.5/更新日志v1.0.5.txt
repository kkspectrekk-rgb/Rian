Rain v1.0.5 更新日志

1. 重新设计 Rain 应用图标，移除所有圆形和水滴形元素。
2. 图标中的雨全部统一为同角度、同线宽、圆角端点的白色斜雨线。
3. 同步替换 Windows EXE/任务栏图标、系统托盘图标和 Rain 界面内品牌图标。
4. 图标改为由项目脚本精确生成，后续可重复生成一致的 PNG 与多尺寸 ICO 文件。
5. 更新 GitHub 仓库主页中的 Rain 图标、版本信息和下载入口。
6. 继续沿用原用户数据目录，升级后会保留已有 API Key、喜欢的音乐、最近播放和本地缓存。
7. 提交前增加密钥模式扫描；API Key 与 settings.json 不会加入 Git 仓库或 Release。
8. 本版本仍仅提供 Windows x64 免安装便携版，不生成 Setup 安装包。

说明：API Key 继续由 Windows safeStorage 加密并保存在 %APPDATA%\Aurora Music\settings.json。V1.0.5 项目目录与 Git 仓库均不包含该文件。
