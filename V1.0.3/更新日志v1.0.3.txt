Rain v1.0.3 更新日志

1. 修复 ChKSz API 账户页点击“使用 LinuxDo 继续”时登录弹窗被桌面程序拦截的问题；登录窗口与账户页共用会话，关闭后自动刷新额度状态。
2. 移除启动时的演示歌曲、演示封面和演示歌词，初始播放器统一显示“未播放歌曲”。
3. 新增顺序播放、随机播放、单曲循环三种播放模式；切换时显示提示，并在歌词页歌曲信息旁显示当前模式。
4. 新增逐字歌词效果：歌词按播放进度逐字点亮，当前演唱字词轻微上浮，唱过后回落；同时兼容系统“减少动态效果”设置。
5. 改善网易云音乐、QQ 音乐、酷狗音乐搜索结果的歌手、专辑与封面字段解析。
6. 新增本地搜索、歌曲信息、封面与音频缓存；已经听过且缓存成功的歌曲可减少重复 API 调用。
7. 最近播放和喜欢的音乐优先使用本地缓存补全歌曲信息与封面，并统一使用 Rain 图标作为缺省封面。
8. 调整歌词页顶部安全区域和窄窗口布局，避免翻译、音标、音质控件与 Windows 最小化、最大化、关闭按钮重叠。
9. 本版本仅生成免安装便携版 Rain 1.0.3.exe，不再生成 Setup 安装包。

说明：用户设置、API Key、喜欢的音乐、最近播放和账户登录状态继续沿用原有 Rain/Aurora Music 本地数据目录，不会因为版本升级自动清空。
