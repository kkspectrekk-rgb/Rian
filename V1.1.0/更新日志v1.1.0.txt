Rain v1.1.0 更新日志

1. 歌词取消逐字白色高亮和上下回落效果，当前行整句完成后滚动到下一句，并优化滚动渲染以降低卡顿。
2. 我的歌单中的每个歌单点击后打开独立详情页，不再展开内嵌下拉列表。
3. 修复网易云歌单导入后封面没有读取到的问题。
4. 播放栏音量旁的“最近播放”改为“当前列表”，点击可查看并播放当前队列中的歌曲。
5. 专辑详情页、歌手详情页和歌单详情页新增“全部播放”按钮，点击后替换当前列表并顺序播放。
6. “现在就听”改为“首页”，首页的最近播放改为独立页面，并加入“全部播放”按钮。
7. 调整首页头像位置，并避免进入歌词详细页时头像偶尔浮现在歌词上方。
8. 将全部播放按钮移到标题附近，避免被窗口最小化、全屏和关闭按钮遮挡；喜欢的音乐和本地歌曲也加入全部播放。
9. 移除首页右上角重复的“导入音乐”按钮，保留“导入本地音乐”入口。
10. 首页头像移到“导入本地音乐”卡片上方，并保持听歌概览弹窗可用。
11. 外部播放栏和歌词页进度条增加圆形进度点，外部进度条鼠标样式恢复为食指指针。
12. 最近播放页面新增返回首页按钮。
13. 外部播放栏的播放模式按钮改为顺序播放、随机播放、单曲循环三档循环切换。
14. 设置页新增“检查更新”，启动时会检测 GitHub 最新便携版；发现新版本后弹窗展示更新日志，可立即下载并自动替换当前 EXE，重启后保留本机缓存和 API Key。
15. 搜索结果的每首单曲新增喜欢收藏按钮，可直接加入或移出喜欢的音乐。
16. 首页头像移到“你的音乐”标题旁边并放大，头像图片完整铺满圆形；听歌柱状图鼠标悬停时显示分钟数；导入本地音乐卡片恢复原始大小。
17. 我的歌单中每个已添加的歌单新增删除按钮。
18. 移除歌单删除按钮旁边的进入箭头，避免两个操作图标重叠。
19. 首页头像弹窗改为向右展开，头像裁切比例与设置页一致并完整铺满圆形；修复进入歌词页时头像仍停留在原处的问题。
20. 修正头像圆形按钮默认内边距导致的露底问题，图片现在铺满整个圆形；歌单删除按钮垂直居中。
21. 歌词页将顺序、随机、单曲循环整合为一个循环按钮，左侧原模式按钮改为收藏按钮。
22. 修复歌词页顶部透明拖拽区域遮挡窗口最小化和全屏按钮的问题。
