Rain V1.0.7 更新日志
发布日期：2026-08-17

一、窗口与歌词页面
1. 修复移除原生标题栏后，窗口底部出现空白区域的问题；应用内容现在始终贴合 Windows 窗口边界。
2. 修复歌词页顶部透明拖拽区域遮挡关闭、翻译、音标和音质控件的问题；交互控件移至安全命中区域。
3. 歌词页不再显示重复的底部迷你播放器，并新增歌曲信息旁的“收起歌词”按钮。
4. 歌词区域支持鼠标滚轮手动浏览；手动滚动后会暂时停止自动居中，避免视图被立即拉回。
5. 点击歌词或拖动播放进度时保留目标时间，不再重新从歌曲开头播放；切换音质时也会恢复原进度。
6. 歌词页左侧模式按钮在随机播放和单曲循环之间切换，右侧保留顺序播放按钮。

二、搜索与资料详情
1. 搜索页面改为常驻状态：切换到其他页面再返回时，关键词、分类与结果仍然保留，不会重复调用 API。
2. 搜索结果新增“关闭结果”按钮；只有主动关闭或发起新搜索时才清空当前结果。
3. 歌曲点击后只开始播放，不再自动跳转歌词页；歌词详细页由用户主动打开。
4. 歌手和专辑卡片可以进入独立详情页；首次打开使用一次搜索调用获取匹配曲目，之后优先读取本地缓存。
5. 扩充 QQ 音乐与酷狗音乐封面字段兼容；搜索接口没有返回图片时显示稳定的本地渐变占位封面，歌曲解析成功后缓存真实封面。

三、头像
1. 设置页更换头像时新增圆形裁剪面板，可拖动图片并使用滑杆缩放。
2. 裁剪结果以 512×512 图片保存在本机；主页与设置页头像使用居中裁切并铺满圆形区域。

四、设计与兼容性
1. 歌词页进出场、头像裁剪弹窗和详情页交互遵循 Apple 风格的快速缓动，所有 UI 动画均控制在 300ms 内。
2. 完善“减少动态效果”适配：关闭位移动画，保留必要的透明度和颜色反馈。
3. API Key、登录会话、收藏和缓存继续使用 %APPDATA%\Aurora Music，升级到本版本无需重新填写 Key。
4. API Key 不进入源码、构建产物清单或 Git 仓库。
