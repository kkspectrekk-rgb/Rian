Rain v1.0.6 更新日志
发布日期：2026-08-17

一、界面与动效
1. 继续按照 Emil Kowalski 的界面打磨与动效标准开发，并结合 Apple 式空间连续性。
2. 歌词详细页新增向上滑入、向下滑出的过渡动画；进入 230ms、退出 180ms，只使用 transform 与 opacity。
3. 支持 Windows“减少动态效果”，开启后移除位移动画并保留轻微透明度反馈。
4. 移除原生顶部整条标题栏，最小化、最大化/还原、关闭按钮改为页面右上角的紧凑自绘控件。
5. 修复歌词详细页顶部控件与窗口按钮重叠、页面底部出现空缺的问题。

二、歌词修复
1. 修复逐字歌词被通用 span 样式误设为 12px 的问题。
2. 当前演唱文字与其他歌词保持相同字号，不再缩小。
3. 未唱到的字词保持低透明度；当前字词变白并轻微上浮，唱过后回落到基线。

三、主页、头像与听歌统计
1. “现在就听”顶部自动显示系统星期和 24 小时制当前时间，每 30 秒同步。
2. 设置页面新增自定义头像，图片只保存在本机，不会上传到 Git。
3. API 网站登录且页面可读取用户名时同步显示用户名；未登录或网站未暴露用户名时显示“Rain 用户”。
4. 鼠标悬停头像时向下展开听歌统计；点击可常驻，点击外部后向上收回。
5. 统计累计听歌分钟/歌曲、今日听歌分钟/歌曲，并提供日、周、月趋势切换。

四、搜索优化
1. 搜索结果新增“综合、单曲、歌手、专辑”四个分类。
2. 一次搜索调用后在本机内存与缓存中生成全部分类，切换分类不会再次调用 API。
3. 歌手和专辑由同一批歌曲结果在本机聚合，不额外消耗调用次数。
4. 新增最近搜索记录，默认展示 5 条，可展开到最多 15 条。
5. 歌手、专辑结果新增爱心按钮，可收藏到资料库的对应分类。

五、资料库
1. 新增“歌手”“本地歌曲”“我的歌单”页面，并完成“专辑”页面。
2. 原“歌曲”入口更名为“我的歌单”。
3. 本地歌曲页面新增“添加文件”，本地文件路径和歌曲资料保存在本机，重启后仍可显示和播放原文件。
4. 支持识别网易云音乐、QQ 音乐、酷狗音乐歌单分享长链接。
5. 网易云歌单使用文档提供的 /api/163_playlist 接口，通过一次调用补全整张歌单的歌曲信息。
6. 当前 API 文档没有 QQ 音乐、酷狗音乐歌单详情接口，因此这两个平台只保存分享链接并明确提示，不伪造接口、不产生无效调用。

六、安全与兼容
1. API Key 继续使用 Windows safeStorage 加密保存在 %APPDATA%\Aurora Music\settings.json。
2. V1.0.6 沿用原用户数据目录，升级后保留之前的 API Key、喜欢的音乐、最近播放和媒体缓存。
3. 源码、更新日志、Git 提交和 GitHub Release 均不包含用户 API Key 或 settings.json。
4. 本版本仍只提供双击即用的 Windows x64 免安装便携版，不制作安装包。

已知限制
1. API 网站用户名能否同步，取决于已登录页面是否向 Rain 暴露可识别的用户名元素。
2. QQ 音乐和酷狗音乐歌单详情需要 API 服务后续提供正式接口后才能自动补全。
