# Rain 1.1.6 液态玻璃试用版

## 从 1.1.3 升级后有什么变化

- 新增真正透明的窗口背景，可看到桌面或下方窗口；设置中可调透明度、高光、系统磨砂并实时预览，也可恢复不透明外观。
- 封面光晕跟随真实音乐强弱律动，增强起伏，保留封面四边配色。
- 返回按钮悬浮显示，加入页面前进/后退和滚动位置恢复。
- 网易云、QQ 歌单支持刷新；歌手与专辑名称支持点击搜索，歌曲列表加入正在播放定位按钮。
- 音标按钮替换为十段均衡器（31 Hz–16 kHz，-12 至 +12 dB），支持拖动、整数输入和记忆。
- 修复歌词页顶部拖拽、音质菜单和窗口按钮遮挡，统一顶部按钮对齐。

## 安装

下载附件 `Rain.1.1.6-liquid-setup.exe`，关闭播放器后运行安装。保留原用户数据目录以沿用设置和本地数据；重要数据建议先备份。程序未签名，Windows 可能显示未知发布者提示。

液态玻璃为试用外观，不是 iOS 原生折射；实际效果与 Windows 版本及显卡有关。不适应时可在设置中关闭。1.1.4、1.1.5 为本地中间迭代，本次统一发布为 1.1.6。

仓库源码已统一迁移到 `app/`，各版本日志位于 `docs/releases/`。安装包不包含个人 API Key、登录会话或缓存。
