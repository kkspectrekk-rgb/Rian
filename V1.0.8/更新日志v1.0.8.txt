Rain V1.0.8 更新日志
发布日期：2026-08-17

新增功能
1. 新增窗口内键盘快捷键：空格播放/暂停，Alt+← 上一首，Alt+→ 下一首，Alt+↑ 增加音量，Alt+↓ 降低音量。
2. 设置页新增“键盘快捷键”管理区域，每项快捷键均可单独修改。
3. 支持 Ctrl、Alt、Shift、Win 与普通按键、方向键、功能键等组合输入。
4. 录制快捷键时实时显示当前组合，并在全部按键松开后自动保存。
5. 新增快捷键重复检测、Alt+F4 系统快捷键保护和一键恢复默认设置。

交互与安全
1. 快捷键仅在 Rain 窗口处于前台时生效，不会抢占其他软件的键盘操作。
2. 在 API Key 输入框、文本输入、按钮、下拉菜单和弹窗中操作时，播放快捷键会自动停用，避免误触。
3. 快捷键设置保存在当前设备的本地用户数据中，不会上传到服务器或 Git 仓库。
4. API Key 继续沿用 %APPDATA%\Aurora Music\settings.json 中的 Windows 加密存储；升级本版本不会清除或上传原有 Key。

验证结果
1. 已通过 Vite 正式构建。
2. 已在 Windows 桌面程序中验证组合键松开保存、恢复默认、空格播放控制和 Alt+↑ 音量调节。
3. 已确认默认快捷键及自定义快捷键界面可被 Windows 辅助功能正确识别。
